# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Everyone who takes part, in issues, pull requests, reviews and anywhere else the project is discussed, is
expected to follow it.

In short: be welcoming and patient, assume good intent, keep criticism about the work rather than the person, and
accept that maintainers may decline a contribution.

## Reporting

If someone's behaviour worries you, contact the maintainers privately through the
[Tekthar organization page](https://github.com/tekthar). Please don't raise it in a public issue. Reports are read by
the maintainers only and kept confidential, and we will tell you what we decided to do.

Maintainers who don't follow the Code of Conduct may be removed from the project.

## Enforcement

Maintainers decide what to do about behaviour that breaks the Code of Conduct, following the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a correction, a warning, a temporary ban or a permanent ban, depending on how serious and how repeated it is.
